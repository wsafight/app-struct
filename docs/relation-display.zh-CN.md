# 关系展示

实体可以声明 `display_field: number`，把文本、枚举、UUID 或整数字段用作记录标签。编译器会把该同级字段解析进 Typed IR；未知或不支持的字段会被拒绝。未声明时，Web 先使用第一个文本字段，再回退到主键。被脱敏或为空的展示字段会回退到主键；标签从不授予额外访问权限。

生成的列表和详情通过 `GET /api/<resource>/_lookup?ids=<comma-separated-ids>` 批量加载相关记录。每次请求接受 1-100 个 ID，并应用目标实体的读作用域、租户、软删除和自定义读 Policy，同时脱敏受保护字段。不可用的 ID 会被省略；顺序不保证。该端点从不写入数据，也不为编辑建立 ETag。编辑器在修改记录前会先加载当前详情。

生成客户端提供 `resourceApi.lookup(ids, options)`。Web 把每批结果缓存在目标资源的查询键下，因此普通变更失效也会刷新相关标签。标签会链接到已授权记录。缺失和不可用的关系仍保留已存储的标识符。
