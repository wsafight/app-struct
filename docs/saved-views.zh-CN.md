# 保存视图

生成的资源列表可以把当前搜索、筛选、排序、可见列、每页条数和回收站模式保存为可复用视图。已认证应用会在服务器上存储私有视图和团队视图；仅浏览器本地的视图仍可用于本地或未认证场景。当前列表状态也可以复制为 URL，而不创建保存视图。

私有视图仅对创建者可见。团队视图需要有效的 `X-AppStruct-Tenant` 上下文，并可由该组织成员读取。无论是私有还是团队视图，都只有创建者可以更新或删除。数据库唯一性范围是所有者、租户范围、资源和名称，因此保存已有的自有名称会更新该视图，而另一名成员可以保留同名显示名称的视图。

服务器更新和删除需要通过 `If-Match: "rev-<revision>"` 提供最新修订。过期操作会失败并返回 `412 CONCURRENT_MODIFICATION`；缺少前置条件会返回 `428`。查询状态是不透明的，但限制为 4096 字节，选中时会通过生成的路由校验器回传。

API 表面为：

- `GET /api/saved-views?resource=<resource>` 列出自有视图和可见的团队视图。
- `POST /api/saved-views` 创建私有或团队视图。
- `PATCH /api/saved-views/{id}` 更新自有视图。
- `DELETE /api/saved-views/{id}` 删除自有视图。
